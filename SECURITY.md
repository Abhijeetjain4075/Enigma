# Security Policy

## Current status

Enigma is currently a research/concept repository and does not represent a production service.

## Reporting

Do not publish sensitive security details in public issues.

For a future production implementation, a private security reporting channel must be established before handling real credentials, payment data, or physical-world control.

## Security priorities

Highest priority areas include:

1. authorization
2. remote service control
3. payment and settlement
4. partner credentials
5. identity and delegation
6. location and journey data
7. webhook authenticity
8. supply-chain security

## Responsible engineering

Production systems should implement secret management, least privilege, encryption, dependency scanning, audit logging, key rotation, incident response, backup and disaster recovery, penetration testing, and security review of every provider adapter.
