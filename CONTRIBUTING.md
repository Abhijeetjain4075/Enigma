# Contributing to Enigma

## Current stage

Enigma is a research and architecture repository. Contributions should improve evidence, architecture, specifications, experiments, or implementation quality.

## Principles

- Prefer primary sources.
- Record assumptions.
- Separate facts from hypotheses.
- Never claim an integration that has not been tested.
- Preserve provider neutrality.
- Treat financial and physical-world actions as high-risk.
- Keep changes focused.

## Research contributions

A research change should include source, retrieval date, claim, confidence, implications, and open questions.

## Engineering contributions

Implementation changes should include tests, error behavior, security considerations, observability, and migration/versioning impact.

## Commit discipline

Use atomic commits with messages that explain one coherent change. Avoid meaningless formatting-only commits unless formatting is the actual purpose.

## Scope

Do not add unrelated consumer features merely because they could be technically integrated.
