# Enigma Launch Readiness Gate

Enigma is not launch-ready merely because an API works in a sandbox.

## Product

- [ ] target customer identified
- [ ] problem validated by interviews
- [ ] paid/committed design partner
- [ ] measurable workflow outcome
- [ ] support model

## Provider

- [ ] contractual permission
- [ ] API/protocol permission
- [ ] transaction permission
- [ ] production credentials
- [ ] provider support contact
- [ ] kill switch

## Technical

- [ ] canonical model
- [ ] adapter
- [ ] idempotency
- [ ] event processing
- [ ] reconciliation
- [ ] observability
- [rate limiting
- [ ] disaster recovery
- [ ] rollback

## Security

- [ ] threat model
- [ ] secret management
- [ ] least privilege
- [ ] webhook authentication
- [ ] dependency/SAST scanning
- [ ] penetration testing appropriate to risk
- [ ] incident response

## Financial

- [ ] payment-provider contract
- [ ] merchant-of-record decision
- [ ] tax treatment
- [ ] refund/dispute workflow
- [ ] settlement process
- [ ] accounting treatment

## Legal/privacy

- [ ] data-role analysis
- [ ] privacy notice
- [ ] terms
- [ ] retention schedule
- [ ] applicable rights workflows
- [ ] cross-border assessment
- [ ] consumer protection review

## Operations

- [ ] SLOs
- [ ] runbooks
- [ ] incident escalation
- [ ] reconciliation owner
- [ ] customer support
- [ ] partner support

## Evidence

- [ ] sandbox evidence
- [ ] controlled production evidence
- [ ] repeated successful transactions
- [ ] failure/recovery evidence
- [ ] unit economics

A launch gate is passed only when every mandatory control has evidence and an accountable owner.
