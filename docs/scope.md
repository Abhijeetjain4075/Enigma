# Scope

## Core

Enigma is software for interoperability, orchestration, identity, authorization, transactions, settlement, and intelligence.

## Initial domain

EV charging.

### Charging capabilities

- Station discovery
- Connector compatibility
- Live status
- Tariff normalization
- Session authorization
- Remote start and stop where supported
- Session monitoring
- Billing
- Receipts
- Refunds
- Roaming
- Settlement
- Reliability intelligence
- Route-aware charging

## Adjacent domains

### Mobility

- Parking
- Tolls
- Public transit integrations
- Rentals
- Fleet services
- Roadside assistance

### Vehicle services

- Maintenance
- Repairs
- Parts
- Inspection
- Service booking

### Energy

- Home charging
- Solar
- Battery storage
- Energy management
- Grid services
- Vehicle-to-grid where commercially and technically supported

### Commercial infrastructure

- Fleet expense
- Corporate mobility
- OEM embedded charging
- Developer APIs
- Enterprise orchestration

## Explicitly outside core ownership

- Manufacturing chargers
- Manufacturing vehicles
- Manufacturing batteries
- Owning physical parking assets
- Owning toll infrastructure
- Operating electricity grids
- Becoming an insurer
- Becoming a bank

These businesses may remain integration partners.

## Scope rule

A new feature belongs in Enigma when it creates reusable interoperability between participants or simplifies a meaningful transaction involving mobility, vehicles, energy, or associated services.

If a feature is merely a standalone consumer utility with no interoperability value, it should be treated as a separate product hypothesis.
