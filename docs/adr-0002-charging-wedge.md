# ADR-0002: Charging as Initial Wedge

## Status

Accepted as a hypothesis, not a commitment.

## Decision

Use EV charging as the initial research and validation domain because it exposes discovery, compatibility, authorization, session, billing, settlement and reliability problems in one workflow.

Do not assume charging must remain the permanent product boundary.

## Exit condition

Move beyond charging only after a measurable transaction workflow has demonstrated:

- provider permission
- customer value
- reliable execution
- reconciliation
- viable economics

## Reversal condition

Change the wedge if another domain provides materially stronger evidence of willingness to pay, integration feasibility, or residual market gap.
